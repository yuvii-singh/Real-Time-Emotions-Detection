# Real Time  Emotion Detection

- Kaggle Dataset :- https://www.kaggle.com/c/challenges-in-representation-learning-facial-expression-recognition-challenge/data.

- Use train.py file to train the model.

- Change the number of classes according to you.

- Do Experiment with different pre-trained models.

- Execute the test.py file to run the Emotion Detection.

- Working in real-time using webcam.

- Streming the video from webcam and detecting the emotions of multiple faces in real-time.

-Save the emotion reports in a CSV file.

- Detecting majority emotion of the people in the frame.

Real-Time Emotion Detection using Python, OpenCV, CNN, and Streamlit. The project detects multiple faces through a live webcam, classifies facial expressions as Angry, Happy, Neutral, Sad, or Surprise, generates session-wise emotion reports, and stores analysis results in CSV format.
